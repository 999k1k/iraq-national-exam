# منصة الاختبار الوطني — تحضير الدراسات العليا في العراق

موقع ثابت (HTML/CSS/JS بدون أدوات بناء) لتحضير الاختبارات الوطنية الموحدة: العربية (60 سؤالاً) والإنكليزية INELT (40) والحاسوب INCPT (40)، 60 دقيقة لكل اختبار.
الموقع المباشر: https://999k1k.github.io/iraq-national-exam/

## المحتويات
- **دليل الاختبار** (`#/guide`): الجهة المنظمة، الأهلية، خطوات الحجز، الرسوم والمواعيد، شكل الاختبار والمنهج، درجات الاجتياز لكل مادة ونوع دراسة (مع CEFR للإنكليزي)، يوم الاختبار (ما تحضره/الممنوعات/الغش)، النتيجة والشهادة، أسئلة شائعة، والمصادر. كل معلومة موسومة: رسمي / تجارب الطلبة / نصيحة، مع رابط مصدرها.
- **خطة المذاكرة** (`#/plan`): خطة 14 يوماً وخطة 30 يوماً مع مهام قابلة للتأشير.
- **الملخصات** (`#/study/:مادة`): ملخص كامل + ورقة مراجعة سريعة + **المصطلحات** (`#/glossary`).
- **التدريب** (`#/practice/:مادة`): 2,575 سؤالاً بالشرح، حسب الموضوع أو «أخطائي السابقة»، ترتيب ذكي.
- **الامتحان التجريبي** (`#/mock`): نفس عدد الأسئلة والوقت وتوزيع المواضيع (الإنكليزي: قطعتان × 5 أسئلة)، مؤقّت يُسلّم تلقائياً، علامة مراجعة، خريطة أسئلة، استئناف بعد إعادة التحميل.
- **تقدّمي** (`#/progress`): الدقة لكل مادة، سلسلة الأيام، خريطة النشاط، المواضيع الأضعف، منحنى الدرجات.
- وضع التركيز (يخفي القوائم)، الوضع الداكن، مؤقّت بومودورو، اختصارات لوحة المفاتيح (1–4 / A–D / أ–د، ←/→، F، G، Enter، Esc)، يعمل دون اتصال (Service Worker) ومن ملف محلي.

## البنية
- `data-src/*.js` — مصدر الأسئلة (لا يحمّله الموقع).
- `tools/build-bank.js` — يطبّق `tools/fixes.js` (حذف/تصحيح) ويولّد `js/bank/{arabic,english,computer}.js` و`js/bank/meta.js` (تحميل كسول لكل مادة). شغّل: `node tools/build-bank.js`.
- `js/guide.js` — محتوى الدليل والخطط والمصطلحات وأوراق المراجعة. `js/notes.js` — الملخصات. `js/app.js` — التطبيق.
- كل البيانات الشخصية في `localStorage` بالبادئة `ine_`.

## إعادة توليد ملفات PDF
```
python3 -m http.server 8765
google-chrome --headless=new --no-sandbox --virtual-time-budget=20000 --no-pdf-header-footer \
  --print-to-pdf=files/arabic-bank.pdf "http://localhost:8765/print.html?doc=arabic-bank"
```
(وكذلك english-bank، computer-bank، arabic-notes، english-notes، computer-notes)
